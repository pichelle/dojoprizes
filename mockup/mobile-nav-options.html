Recommendation

Bottom tab bar for the 4 main sections, hamburger-style "More" for the rest

Requests, Prize Bin, Checkouts, and Filaments are peers — there's no primary/secondary relationship between them, and switching between them is probably the single most common action on the whole site. A hamburger buries that behind an extra tap every single time, which adds up fast on a phone used for quick shelf checks between classes.

A bottom bar keeps those 4 exactly where thumbs already rest, and folds MakerWorld / Tinkercad / profile switch / feedback / log out — things opened rarely, if ever, in a session — into the "More" sheet, which is really just a hamburger drawer in a different position. So this isn't really "hamburger vs. bottom bar" as an either/or: it's using each pattern for the tier of navigation it's actually good at.

One open question worth deciding before this gets built: the active profile switcher (top of the current desktop nav) needs a new home on mobile too — either folded into the "More" sheet as shown here, or kept visible somewhere in the top status area since switching profiles happens more often than opening MakerWorld.
